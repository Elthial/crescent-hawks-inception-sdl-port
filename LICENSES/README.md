# Licensing map

The repository contains materials with different legal status. Location is the
primary guide; an explicit notice in a file takes precedence.

| Path | Status |
| --- | --- |
| `src/SDL`, `tests`, `tools`, build scripts | Project-authored; MIT to the extent contributors hold the rights |
| Project-authored documentation | MIT to the extent contributors hold the rights |
| `src/Original` | Reconstructed from the proprietary executable; excluded from the MIT grant |
| `evidence` | Annotations, assembly, metadata and research evidence; excluded from the MIT grant |
| `docs/images` | Title-derived artwork and current-build screenshots used for project identification and documentation; original-rights material excluded from the MIT grant |
| Recovered game text, data tables and names | Original-rights material; excluded from the MIT grant |
| SDL | zlib license; see `THIRD_PARTY_NOTICES.md` |
| `assets/original-game` | Ignored user-supplied material; never part of this repository |

[`MIT.txt`](MIT.txt) contains the unmodified MIT license for covered material.
The scoped root [`LICENSE`](../LICENSE), [`NOTICE.md`](../NOTICE.md), and this
map must be read together. No license to the original game is granted.
