# Original game files go here

Copy or install your legally obtained *BattleTech: The Crescent Hawk's
Inception* data files into this directory for the default local launcher.
`INFOCOM.CMP` must be present; normal play requires the rest of the original
installation as well.

The contents of this directory are ignored by Git. They are not part of this
preservation source repository and must not be committed or redistributed.

You may keep the installation elsewhere and pass its directory to
`Run-Inception.ps1 -OriginalAssetDirectory <path>` instead.
